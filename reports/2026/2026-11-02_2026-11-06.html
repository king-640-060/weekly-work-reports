（二）B 端运营支撑

项目名称 本周完成工作 下周计划
API 发券活动数据看板

1、完成 API 发券活动数据看板搭建，支持按活动、日期范围及业务核销方筛选，并按日、周、月查看核销数量、应付金额和实付金额变化。

2、增加各业务核销贡献、新老会员核销占比及会员产品表现分析，支持不同维度联动查看。

3、支持数据导入、重复记录去重、异常数据检查，以及含数据离线看板导出，便于持续更新和复用。

1、结合渠道运营使用情况持续更新数据，跟进数据导入、统计口径及展示方面的问题。

会员分销经营看板

1、完成会员分销经营看板搭建，支持导入产品日报，按日期、分销公司（下单场景）及会员产品筛选，汇总销量、销售金额和按配置规则测算的结算金额。

2、支持日、周、月趋势、产品销售贡献及分销公司表现对比，提供近 7 天／30 天销售额及销量增长率分析。

3、支持历史数据增量更新、产品价格及结算规则配置，以及明细和含数据离线看板导出。

1、结合渠道日报更新与周度数据同步，持续维护看板数据，核对销售及结算统计口径。

品牌合作权益交付

1、对接三家合作品牌，完成合作素材设计稿准备，并提交对应设计需求，推进品牌活动素材制作。

2、按品牌要求整理并填写权益／运营配置模板，梳理体验卡权益、发放数量、兑换期限、领取限制、使用范围及兑换流程等交付信息。

3、完成三家品牌对应的 API 发券券配置，为后续品牌侧权益发放做好准备。

1、跟进设计需求及品牌侧素材反馈，按合作进度补充交付资料，配合后续权益发放及问题处理。

渠道日常运营支撑

1、承接渠道日常运营支撑工作，工作范围涵盖打款确认、售卖预警跟进、退款相关权益处理、品牌权益交付及渠道销售数据同步。

1、每日查看渠道售卖及预警情况，对达到预警条件的渠道跟进补款；按实际打款核实到账、反馈回单，并同步更新打款台账、累计金额及预警配置。

2、按实际退款申请核对订单，完成相应权益取消及退款登记，保留后续对账记录。

3、根据新增合作需求推进品牌素材、优惠券配置及交付资料准备，并协助新渠道完成开放平台注册。

4、每周五整理各渠道前一周周五至本周四的会员销售数据，分渠道核对并同步。
